02 Small, useful recipes

        

        

          

            
Load a packed file

            

              A .gp16 payload contains UTF-16LE code units. Read bytes before
              decoding text.
            

            
import {binary} from './full.min.mjs';

const res = await fetch('asset.gp16');
const payload = new TextDecoder('utf-16le')
  .decode(await res.arrayBuffer());
const bytes = binary(payload);

          

          

            
Restore structured data

            

              JSON, manifests and configuration keep their exact original UTF-8
              bytes.
            

            
const bytes = binary(payload);
const json = JSON.parse(
  new TextDecoder().decode(bytes)
);
console.log(json);

            
          

          

            
Restore a compressed asset

            

              Inflation is a second, explicit step. The gzip log example uses
              this exact flow.
            

            
const compressed = binary(payload);
const stream = new Blob([compressed])
  .stream().pipeThrough(
    new DecompressionStream('gzip')
  );
const bytes = new Uint8Array(
  await new Response(stream).arrayBuffer()
);

            
          

          

            
Package a file offline

            

              “Make standalone HTML” includes the decoder and your payload. It
              runs from a local file with no neighboring assets.
            

            
glyphpack encode input.bin \
  --checksum secure -o asset.gp16

03 See the checks work

          
        

        

          Real inputs sent to the decoder: a changed byte, a truncated header,
          and a noncanonical representation. These do not change your workbench.
        

        

          Run the examples to compare byte integrity with format verification.
        

        

          BLAKE3 is an unkeyed digest. It detects corruption; someone who can
          replace both data and digest can calculate a new one.
